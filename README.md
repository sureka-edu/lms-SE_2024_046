Library Management System

Project Description
The Library Management System is a Java-based application designed to manage library operations efficiently.

 Features
- Manage library members.
- Manage students and staff.
- Manage DVDs and library resources.
- Track borrowed and returned items.

 Technologies Used
- Java
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

 Project Structure
The project contains Java classes such as:
- Main
- Library
- Member
- Student
- Staff
- DVD

## Purpose
This project was developed as part of the Object-Oriented Programming coursework to demonstrate the practical application of Java and OOP concepts.
